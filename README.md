# Tree Miner

木を切って製材所で売り、お金で強化して効率を上げていく 3D の作業ゲーム（放置／ハイパーカジュアル系）です。Godot 4 で作っています。

## コアループ

1. 森で木に近づくと自動で伐採し、丸太を背負う（運搬容量まで）
2. 製材所の投入口（黄色い床）に立つと丸太を渡す
   - 製材ライン未開放のとき: その場で丸太を売る
   - 製材ライン開放後: 丸太が板に加工され、出口（水色の床）に積まれる。板を出荷場（緑の床）へ運ぶと丸太の2倍の値段で売れる
3. 稼いだお金で強化する（画面右下の「強化」）
4. 柵の前のオレンジの床に立つとお金を払い、奥のエリアを開放できる

## 木とエリア

| 木 | 硬さ（=必要ダメージ） | 丸太の売値 |
|---|---|---|
| 若木 | 3 | ¥3 |
| マツ | 6 | ¥6 |
| カエデ | 12 | ¥12 |
| カシ | 24 | ¥24 |
| コクタン | 48 | ¥48 |

売値は硬さに比例します（`price_per_hardness`）。拠点に近いエリアほど柔らかい木が多く、遠いエリアほど硬い木が多くなりますが、重み付きの抽選なので多少は混ざります。

| マツの丘 | ¥150 | マツ |

## 強化

| 強化 | 効果 |
|---|---|
| 斧の威力 | 1回の伐採ダメージ |
| 運搬容量 | 一度に運べる丸太・板の数 |
| 移動速度 | 歩く速さ |
| 製材ライン | Lv1で開放、以降は加工速度アップ |
| 伐採員 | 自動で木を切って製材所に運ぶ NPC を雇う |

## 実行方法

1. [Godot 4.3 以降](https://godotengine.org/download)（標準版）をインストール
2. Godot のプロジェクトマネージャーで「インポート」から、このフォルダの `project.godot` を選ぶ
3. F5 で実行

### 操作

- スマホ: 画面のどこかを触ってドラッグ（触った場所にスティックが出ます）
- PC: WASD / 矢印キー、またはマウスドラッグ
- デバッグ: F9 で ¥1,000 追加、F10 でセーブを消して最初から

セーブは `user://save.json` に5秒ごと、強化やエリア開放のタイミングで自動保存されます。

## バランス調整

数値はすべて [`data/balance.json`](data/balance.json) にあります。コードを触らずに調整できます。

- `economy.price_per_hardness`: 硬さ1あたりの丸太の売値
- `economy.plank_multiplier`: 板の売値の倍率（丸太の売値 x この値）
- `trees[]`: 木の種類。`hardness`（硬さ＝売値の基準）、`respawn_sec`（再生までの秒数）、見た目の色・大きさ
- `areas[]`: エリア。`unlock_cost`（開放費用）、`tree_count`（木の本数）、`weights`（木の出現の重み）
- `upgrades[]`: 強化。値は `base_value + per_level × レベル`、費用は `base_cost × cost_growth ^ レベル`
- `lumberjack`: 伐採員の容量・速度・威力
- `world.seed`: 木の配置の乱数シード

## フォルダ構成

```
autoload/
  game_data.gd     バランスJSONの読み込みと計算（価格・強化値・費用）
  game_state.gd    所持金・強化レベル・開放エリア・セーブ
data/balance.json  バランス設定
scenes/main.tscn   メインシーン（中身は scripts/main.gd が生成）
scripts/
  main.gd          マップ・施設・木・カメラ・UIの組み立て
  fx.gd            プリミティブ生成や浮き上がる文字などのヘルパー
  world/           プレイヤー、木、伐採員、製材所、出荷場、エリアの柵
  ui/              HUD（所持金・積荷・強化パネル）とバーチャルスティック
tests/smoke_test   ヘッドレスで一連のループが動くかを確認するテスト
```

見た目は全てプリミティブ（箱・円柱・球）のプレースホルダです。モデルを差し替えるときは、各スクリプトの `_build...` / `setup` で作っているメッシュを置き換えてください。

## テスト

```
godot --headless --fixed-fps 60 --path . res://tests/smoke_test.tscn
```

伐採→売却→強化→製材→出荷→エリア開放までを自動で操作し、`SMOKE TEST: PASS` が出れば成功です（セーブデータは上書きしません）。
