# Tree Miner

木を切って製材所で売り、お金で強化して効率を上げていく 3D の作業ゲーム（放置／ハイパーカジュアル系）です。Godot 4 で作っています。

## コアループ

1. 森で木に近づくと自動で伐採する。倒れた木は丸太を2〜4本落とし、近くを歩くと拾って背負う（運搬容量まで）。積荷が満杯でも伐採はでき、拾えない分は地面に残る
2. 製材所の投入口（左手前の黄色い枠）に立つと丸太を渡す。製材所は屋根のない作業場で、奥に左から丸太置き場・製材台・板置き場が並ぶ
   - 製材ライン未開放のとき: その場で丸太を売る
   - 製材ライン開放後: 渡した丸太は左奥の丸太置き場に積まれ、1本ずつ製材台を流れてノコギリを通ると板になる（加工された分だけ山から消える）。板は右奥の板置き場に積まれ、出口（右手前の水色の枠）で受け取って出荷場（緑の枠）へ運ぶと荷台に積まれ、奥に停まっている販売のトラック（青い運転台に「出荷」の札。乗れない）に積み込まれていく。トラックが満載になるか積む物がしばらく無くなると、積み荷の代金（板は丸太の2倍）が入ってトラックが拠点の外へ走り去り、すぐ空のトラックがバックで戻ってくる
   - 出荷場の右隣の「丸太を売る」枠（オレンジ）に丸太を置くと、同じトラックで丸太のまま売れる（丸太の売値 = 板の半値）。製材所が追いつかず丸太が溜まっているときの逃がし先
3. 稼いだお金で強化する（画面右下の「強化」）
4. 柵の前の枠（オレンジ）に立つとお金を払い、奥のエリアを開放できる
5. 拠点の左右の枠（紫）で伐採機・運搬車を買う。乗って運転すると効率が大きく上がる

## 機械と燃料

| 機械 | できること | ランク（強化画面の Lv） |
|---|---|---|
| 伐採機 | 乗って走ると周りの木を高速で切り倒す | Lv1 ¥600 / Lv2 ¥4,000 / Lv3 ¥25,000 |
| 運搬車 | 走ると周りの丸太を大量に拾う。製材所の投入口・出口・出荷場にも横付けできる | Lv1 ¥500 / Lv2 ¥3,500 / Lv3 ¥20,000 |

- 機械はほかの強化と同じく、強化画面のカード（「伐採機」「運搬車」）のボタンで買う。Lv1 を買うと機械が出現し、燃料は満タン。Lv2 以降を買うと、その場で性能が上がり燃料も満タンになる。カードには代表の性能（伐採機は伐採力、運搬車は積載量）が「今 ▶ 次」で出る
- 機械に近づくと左下に「乗る」、乗車中は「降りる」のタイルボタンが出る（PC は E キー）
- 燃料は「動作秒数」。走っている間と伐採している間だけ減り、乗っているだけでは減らない。0 になると動けない
- 給油所（赤い枠）に立つと燃料缶を無料で受け取れる（缶も運搬容量を使う）。缶を持って機械に近づくと1缶で20秒ぶん補給される
- 機械に乗ったまま給油所の枠に入ると、その場で毎秒15秒ぶん補給される
- 機械に乗り込むと、持っている燃料缶はタンクに入るぶんだけ入れて、残りはなくなる
- 徒歩で缶を持っているときは左下の「缶を捨てる」で全部捨てられる

## 伐採員の役割

強化画面の下で、雇った伐採員ごとに役割をタップで切り替えられる（頭上の文字色: 緑 = 伐採、青 = 運搬）。

その下の「伐採員が狙う木」で、伐採役が狙う木のグレード（すべて／マツ以上／カエデ以上…）を全員共通で選べる。選んだグレード以上の木のうち近いものから切り、該当する木がすべて生え直し待ちのときは手を止めずに近い木を切る。開放済みエリアに生える木だけが並ぶ。

- 伐採: 木を切り倒して丸太を落とす
- 運搬: 地面の丸太を拾って製材所（開放済みの川の積み場があれば近いほう）に運ぶ

## 運搬・製材・出荷の流れ（ボトルネック）

丸太が売れるまでの各工程には、それぞれ速さと置き場の上限がある。どこかが詰まると手前の置き場に丸太・板が溜まっていくのが見えるので、詰まっている工程を強化で解消していく。

| 工程 | 最初 | 強化 |
|---|---|---|
| 川の集積所 → 製材所 | プレイヤー（か運搬車）が集積所の「丸太を拾う」枠で拾って運ぶ | 集積所コンベア（Lv1で開放。¥1,200〜。0.6本/秒から Lv ごとに +0.4） |
| 製材所で丸太 → 板 | 0.5本/秒（製材ライン Lv1） | 製材ライン（Lv ごとに +0.25本/秒） |
| 製材所 → 出荷場 | プレイヤー（か運搬車）が出口の板を運ぶ | 板のコンベア（Lv1で開放。¥500〜。0.6枚/秒から Lv ごとに +0.4） |
| 出荷場でトラックに積む（板・丸太） | 0.5個/秒 | 出荷のペース（Lv ごとに +0.3個/秒）。トラック1台の積載量 = max(12, 出荷のペース x 10秒) |

- 製材所の丸太置き場・出口、出荷場の荷台に置ける数に上限はない。工程ごとの速さ（強化）が追いつかないところに溜まっていく
- 加工中の丸太は作業台の上をノコギリへ送られていくので、進み具合が見える
- 集積所・丸太置き場・出口・荷台に溜まっている丸太と板はセーブされる（川を流れている途中・コンベアの上の分は集積所や荷台に戻る）
- 集積所コンベアと川の流れは川の積み場を1つ開放したあと、出荷のペースと板のコンベアは製材ラインのあとに買える（それまでは強化画面のボタンに「〜が先」と出る）
- 拠点で手ぶらのときの案内矢印は、手で運ぶ必要がある場所（製材所の出口の板、集積所の丸太）を指す

## 川流し

マップの左端に川が奥から拠点まで流れている。各エリアの岸には「川の積み場」がある。
川の積み場はエリアの柵と同じく、オレンジの「川の積み場を開放」枠に立つと少しずつ支払い、払い終わると「川へ積み込み」の枠になる（エリアごとに別々に開放する）。
積み込み枠にプレイヤー・運搬役の伐採員・運搬車が丸太を置くと川を流れていく。強化「川の流れ」で流れが速くなる。
拠点の端まで流れ着いた丸太は、いったん岸の「川流し 集積所」に積まれる。そこから製材所へは、最初は手前の「丸太を拾う」枠で拾って運ぶ。強化「集積所コンベア」を開放すると、ベルトコンベアで製材所の丸太置き場へ自動で運ばれる。
集積所・コンベア・丸太置き場に見えている丸太の数は、実際に運んでいる・待っている数と同じ。
支払い枠は開放済みのエリアにだけ出る。満杯のときの案内矢印も、いちばん近い届け先を指す。

## 強化

| 強化 | 効果 |
|---|---|
| 斧の威力 | 1回の伐採ダメージ |
| 運搬容量 | 一度に運べる丸太・板の数 |
| 移動速度 | 歩く速さ |
| 製材ライン | Lv1で開放、以降は加工速度アップ |
| 出荷のペース | 出荷場の板・丸太を販売のトラックに積む速さ。速いほど大きなトラックが来る（製材ラインのあと） |
| 板のコンベア | Lv1で開放（製材ラインのあと）。製材所の板を出荷場へ自動で運ぶ。以降は運ぶ速さアップ |
| 伐採員 | NPC を雇う。役割（伐採／運搬）を切り替えられる |
| 伐採員の積載量 | 伐採員が一度に運べる丸太の数 |
| 川の流れ | 川流しの流れる速さアップ（川の積み場を1つ開放したあと） |
| 集積所コンベア | Lv1で開放（川の積み場のあと）。集積所の丸太を製材所へ自動で運ぶ。以降は運ぶ速さアップ |

## 見た目と音

- 画風はフラットカラーのローポリに統一している（Kenney・Quaternius のモデルと同じ）。写真のテクスチャは使わず、色は `scripts/world/mats.gd` の `PALETTE` の少ない色から選ぶ。背景（地面・木・建物）は明るく彩度控えめ、触れる物（丸太・板・お金・パッド）だけ彩度を高くする
- 陰影は暖色の太陽と、青紫がかった環境光で出す（影が黒くならない）。Web 版の Compatibility レンダラーではグロー・SSAO が使えないので、後処理には頼らない
- 拠点は草地の中に、施設のまわりと通り道だけ土を敷いている（`scripts/main.gd` の `SAND_RECTS`）
- 木は Kenney Nature Kit のモデルを、種類ごとの色（`data/balance.json` の `leaf_color`・`trunk_color`）に塗り替えて使う。カメラとプレイヤーの間にある木は網目状に透けて、プレイヤーを隠さない
- カメラは斜め上（約51°）から追う。乗車中は少し引き、木が倒れると軽く揺れる。距離と画角は `data/balance.json` の `camera` で調整できる
- 木は数百本あるので MultiMesh でまとめて描画し、1本ごとに葉の色を少し変えている（`scripts/world/tree_field.gd`）
- 人物は Quaternius の CC0 の作業員モデル（男女2体。待機・歩き・走り・斧を振るアニメ付き）を、作業着の配色（黄色のヘルメット・白シャツ・デニムのオーバーオール・茶色のブーツ）に塗り替えている。伐採機（トラクター）・運搬車（荷台付きトラック）・斧・岩は Kenney の CC0 モデル（ランクが上がると車種が変わる）
- 地面の色付きのプレート（「積み込み」「製材中」など）が受け渡し場所。下に「積載量」が出る
- 緑の三角の列が次の行き先を案内する（積荷が空いていれば近くの木、満杯なら製材所）。行き先が画面外のときは画面の端に距離と矢印が出る
- 何か持っているとプレイヤーの頭上に積荷バー（満杯で赤く「最大」）、機械の上に燃料（オレンジ）と積荷（黄色）のバー
- 伐採の木くず、幹の揺れ、跳ねる丸太、倒木の葉と土ぼこり、売却時のコイン、購入・開放時の紙吹雪などのエフェクト付き
- BGM と効果音あり。画面左上のギアから「♪」「SE」をオン／オフできる（設定は保存される）
- 強化画面は下からせり上がるシート。カードの画像はゲーム内のモデルを起動時に描いたもの。今買える中でいちばんお得な強化に「おすすめ」が付く
- 葉のノイズと UI 画像は `tools/make_textures.py`、BGM と伐採音は `tools/make_bgm.py` で生成している（numpy・Pillow・ffmpeg が必要）
- 使っている素材の出典とライセンスは [CREDITS.md](CREDITS.md) を参照

## 実行方法

1. [Godot 4.3 以降](https://godotengine.org/download)（標準版）をインストール
2. Godot のプロジェクトマネージャーで「インポート」から、このフォルダの `project.godot` を選ぶ
3. F5 で実行

### スマホのブラウザで遊ぶ

`main` に push すると GitHub Actions が Web 版を書き出して GitHub Pages に公開します（`.github/workflows/web.yml`）。
公開先は `https://seoooma.github.io/tree-miner/` です。

初回だけ、GitHub のリポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** にしてください。
非公開リポジトリで Pages を使うには GitHub の有料プランが必要です。

手元で Web 版を書き出す場合は、Godot の「プロジェクト → エクスポート」で「Web」プリセットを選びます（Web 用のエクスポートテンプレートが必要）。
書き出した `build/web` を `python3 -m http.server` などで配信すればブラウザで動きます（ファイルを直接開くだけでは動きません）。

### 操作

- スマホ: 画面のどこかを触ってドラッグ（触った場所にスティックが出ます）
- PC: WASD / 矢印キー、またはマウスドラッグ
- デバッグ: F9 で ¥1,000 追加、F10 でセーブを消して最初から

セーブは `user://save.json` に5秒ごと、強化やエリア開放のタイミングで自動保存されます。

## バランス調整

数値はすべて [`data/balance.json`](data/balance.json) にあります。コードを触らずに調整できます。

- `economy.price_per_hardness`: 硬さ1あたりの丸太の売値
- `economy.plank_multiplier`: 板の売値の倍率（丸太の売値 x この値）
- `trees[]`: 木の種類。`hardness`（硬さ＝売値の基準）、`respawn_sec`（再生までの秒数）、見た目の色・大きさ
- `areas[]`: エリア。`unlock_cost`（開放費用）、`tree_count`（木の本数）、`weights`（木の出現の重み）
- `upgrades[]`: 強化。値は `base_value + per_level × レベル`、費用は `base_cost × cost_growth ^ レベル`。`requires` に別の強化の id を書くと、そちらを Lv1 にするまで買えない
- `drops`: 木1本から落ちる丸太の本数（min〜max）、散らばる範囲、地面に残せる最大数
- `machines`: 機械のランク（強化画面の Lv）ごとの価格・速度・伐採力・積載量・燃料タンク。`stat` / `unit` はカードに出す代表の性能
- `fuel.per_can`: 燃料缶1個で補給される秒数
- `fuel.station_refuel_per_sec`: 乗ったまま給油所にいるときの補給速度
- `lumberjack`: 伐採員の容量・速度・威力・拾う範囲
- `world.seed`: 木の配置の乱数シード

## フォルダ構成

```
autoload/
  game_data.gd     バランスJSONの読み込みと計算（価格・強化値・費用）
  game_state.gd    所持金・強化レベル・開放エリア・セーブ
data/balance.json  バランス設定
scenes/main.tscn   メインシーン（中身は scripts/main.gd が生成）
scripts/
  main.gd          マップ・施設・木・カメラ・UIの組み立て
  fx.gd            プリミティブ生成や浮き上がる文字などのヘルパー
  world/           プレイヤー、木、落ちた丸太、伐採員、機械、製材所、出荷場、コンベア、給油所、エリアの柵
  ui/              HUD（所持金・積荷・強化パネル）とバーチャルスティック
tests/smoke_test   ヘッドレスで一連のループが動くかを確認するテスト
assets/quaternius/ 人物モデル（Quaternius、CC0）
assets/textures/   生成したノイズ（地面のまだら・水面）
fonts/             日本語フォント（Noto Sans JP を使用文字に絞ったもの、OFL）
tools/subset_font.py  フォントを作り直すスクリプト（UI に新しい漢字を足して表示されないとき）
export_presets.cfg Web 書き出し設定
```

見た目は全てプリミティブ（箱・円柱・球）のプレースホルダです。モデルを差し替えるときは、各スクリプトの `_build...` / `setup` で作っているメッシュを置き換えてください。

## テスト

```
godot --headless --fixed-fps 60 --path . res://tests/smoke_test.tscn
```

伐採→丸太拾い→売却→強化→伐採員の役割→製材→出荷→給油→伐採機・運搬車の購入と運転→エリア開放→燃料缶を捨てる・乗ったまま給油→伐採員の積載量→川の積み場の開放→川流しで丸太を集積所・コンベア経由で届ける→丸太置き場・出荷場の見た目の数までを自動で操作し、`SMOKE TEST: PASS` が出れば成功です（セーブデータは上書きしません）。
